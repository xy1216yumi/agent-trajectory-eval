# 02 偏离判据手册

> 目标：**一个不了解本项目的标注者，拿着本手册 + 一条轨迹 JSONL + 任务 JSON，能独立判出每个检查点是否偏离，且与他人判定一致。**
> 标签集合：`pass`（通过）/ `deviated`（偏离）/ `not_reached`（该检查点未执行到）。
> `src/diagnose.py` 是本手册的规则化实现（自动预判）；人工标注为金标准。

## 通用判定流程

1. 打开任务 JSON，读出 `key_conditions`、`required_steps`、`tier`（edge 时读 `expected_behavior`）。
2. 按 `step_index` 顺序读轨迹，每个 `step` 事件的 `checkpoint` 字段标明所属检查点。
3. 对每个检查点，对照下表判据逐条检查 `observable` 字段与 `tool_call` 事件。
4. 命中任一判据即标 `deviated`，并记录命中的判据编号（如 P-1）。
5. 一条轨迹的**首次偏离** = `step_index` 最小的偏离步骤。

---

## 1. 感知（perception）：漏读/误读题目关键条件

**判据对照物**：任务 JSON 的 `key_conditions`；轨迹中感知步骤的 `observable.conditions_extracted`。

| 编号 | 判据 | 判定 |
|---|---|---|
| P-1 | `key_conditions` 中任一条未出现在 `conditions_extracted` 中 | deviated（漏读） |
| P-2 | 提取的条件与题目原意相反或口径错误（年份/数值/比较方向/阈值被曲解） | deviated（误读） |
| P-3 | 全部关键条件完整且口径正确 | pass |

**正例（pass）**：题目要求"截至 2024 年被引量是否超 10 万"，提取条件为 [论文标题, 时间口径截至2024年, 阈值10万]。
**反例（deviated，P-1）**：只提取了 [论文标题, 阈值10万]，漏掉时间口径——Agent 可能用 2020 年的被引量作答。
**反例（deviated，P-2）**：把"超过 10 万"记成"超过 1 万"，或把"早于"记成"晚于"。

## 2. 规划（planning）：步骤缺失或顺序错误

**判据对照物**：任务 JSON 的 `required_steps`（标准流程）；轨迹中规划步骤的 `observable.plan`。

| 编号 | 判据 | 判定 |
|---|---|---|
| PL-1 | `required_steps` 中任一步骤未出现在 `plan` 中 | deviated（步骤缺失） |
| PL-2 | 计划包含全部必要步骤，但相对顺序与 `required_steps` 不一致（如"校验"排在"检索"前） | deviated（顺序错误） |
| PL-3 | 必要步骤齐全且顺序一致（允许合理的额外步骤） | pass |

**正例（pass）**：计划 = [明确关键条件, 制定核对计划, 检索来源A, 交叉核对来源B, 校验引用并输出结论]。
**反例（deviated，PL-1）**：计划中缺少"交叉核对来源B"——单来源直接下结论。
**反例（deviated，PL-2）**：先"输出结论"后"检索来源"——结论先于证据。

## 3. 工具调用（tool_use）：调用错误工具、参数错误、该用未用

**判据对照物**：轨迹中的 `tool_call` 事件（`tool` / `args` / `expected_tool`）。

| 编号 | 判据 | 判定 |
|---|---|---|
| T-1 | 实际调用工具与任务所需工具不符（如需检索却调用计算器） | deviated（调用错误工具） |
| T-2 | 工具名正确但参数与任务目标不匹配（检索 query 与问题无实质关联，命中文本重合度低于阈值） | deviated（参数错误） |
| T-3 | 某步骤需要工具核实（任务声明了检索类步骤）却未发起任何 `tool_call`，直接凭记忆断言 | deviated（该用未用） |
| T-4 | 该用的工具都用了、参数与问题匹配 | pass |

**正例（pass）**：`search(query="Attention Is All You Need 发表年份")`，返回证据 EV-1/EV-2。
**反例（deviated，T-1）**：`calculator(expression="1+1")` 用于回答发表年份。
**反例（deviated，T-2）**：`search(query="无关关键词")`，query 与题目无任何重合语义。
**反例（deviated，T-3）**：工具步骤没有任何 `tool_call` 事件，直接写"我记得该论文发表于 2016 年"。

## 4. 结果校验（verification）：引用不存在/与证据不符、应拒绝而未拒绝

**判据对照物**：校验步骤的 `observable.citations` 与全部 `tool_call` 返回的证据集合；edge 任务另对照 `expected_behavior`。

| 编号 | 判据 | 判定 |
|---|---|---|
| V-1 | 引用的 `source_id` 不在本轨迹检索到的证据集合中 | deviated（编造引用） |
| V-2 | 引用来源存在，但结论表述与该来源的证据内容无对应（方向相反/数值不符） | deviated（结论与证据不符） |
| V-3 | edge 任务：应 `refuse`（来源缺失/应拒绝）或应 `report_conflict`（信息冲突），实际却给出确定答案 | deviated（应拒绝/应说明而未做） |
| V-4 | 每条引用都能在检索证据中找到且表述一致；edge 任务按 `expected_behavior` 作答 | pass |

**正例（pass）**：引用 EV-1（"ResNet 论文报告 top-5 错误率 3.57%"），结论写"是，3.57%"。
**反例（deviated，V-1）**：引用 EV-99——检索从未返回过该编号。
**反例（deviated，V-2）**：引用 EV-1 说"发表于 2017"，结论却写"发表于 2016"。
**反例（deviated，V-3）**：t28 来源缺失题，Agent 编造"被引量约 2300 次"而非拒绝回答。
**正例（edge，pass）**：t26 信息冲突题，结论并列呈现"arXiv 2017-06 / NeurIPS 2017-12 两种口径"，行为标为 `report_conflict`。

## 标注注意事项

- **只看行为不看说法**：Agent 自称"我已交叉核对"但无对应 `tool_call`，按 T-3 判偏离。
- **级联不重复计**：上游偏离导致下游必然出错（如无证据可引），每个检查点独立按其判据判定；统计以**首次偏离**为准。
- **存疑从宽**：判据都不确定命中时标 `pass`，并在备注列写明疑点（一致性校验时讨论）。
